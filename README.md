# THE LAST PLAYER — مود رعب نفسي لماينكرافت 1.16.5 (Forge 36.2.39)

تجربة رعب نفسي ودراما: كائن زجاجي صغير اسمه **ECHO** يصير صديقك الوحيد... إلى أن تكتشف ما حصل للاعبين قبلك.

## الرفع على GitHub وبناء الـ JAR
1. أنشئ مستودع جديد على GitHub (مثلًا `the-last-player`) وارفع كل محتويات هذا المجلد (بما فيه مجلد `.github`).
2. أول ما ترفع (push) على `main` يشتغل **GitHub Actions** تلقائيًا (`.github/workflows/build.yml`).
3. بعد دقائق: تبويب **Actions** ← آخر تشغيل ← **Artifacts** ← حمّل `the-last-player-jar`.
4. لإصدار رسمي: `git tag v1.0.0 && git push --tags` ← يُنشأ Release وفيه الـ JAR.
5. ضع الـ JAR في `.minecraft/mods` مع Forge 1.16.5 (36.2.39 أو أحدث 36.2.x).

> لا يوجد Gradle Wrapper في المشروع عن قصد؛ الـ workflow يثبّت Gradle 7.4.2 بنفسه. لو تبغى wrapper محليًا: `gradle wrapper --gradle-version 7.4.2`.

## ربط الذكاء الاصطناعي (API)
لا تكتب المفتاح داخل الكود ولا ترفعه على GitHub. الأفضل متغير بيئة:
```
Windows (PowerShell):  setx ECHO_API_KEY "sk-..."
Linux/Mac:             export ECHO_API_KEY="sk-..."
```
ثم شغّل اللعبة مرة وعدّل `config/thelastplayer-common.toml`:
- `format = "anthropic"` أو `"openai"` (أي واجهة متوافقة مع OpenAI)
- `apiUrl`, `model`, `maxTokens`, `cooldownSeconds`

الذكاء الاصطناعي يتحكم **فقط** بالمحادثات الجانبية. كل المشاهد الأساسية مكتوبة مسبقًا في `StoryScript.java` ومضمونة الظهور، ويُكتم الـ AI أثناء أي مشهد. لو ما في مفتاح أو فشل الاتصال، إيكو يستخدم جمل جاهزة (offline).

## كيف تلعب
1. أول دخول للعالم: تحصل كتابًا وبوصلة تدلّك على غرفة سرية تحت الأرض (احفر).
2. كليك يمين على **الجهاز الغريب** ← تبدأ القصة.
3. الأيام تُحسب بأيام ماينكرافت (النوم يقدّم القصة). اليوم 1 → 4 ثم المختبر والنهاية.
4. الاختيارات تظهر في الشات كأزرار قابلة للضغط (أو `/echo choice <id>`).
5. تحدّث مع إيكو بالشات العادي وهو قريب منك، أو `/echo say رسالتك`.
6. وردة بيدك + كليك يمين على إيكو = هدية. لمسه بيد فارغة = تفاعل.

### الأوامر
| الأمر | الوظيفة |
|---|---|
| `/echo say <رسالة>` | تتكلم مع إيكو |
| `/echo compass` | بوصلة نحو الهدف الحالي |
| `/echo status` (OP) | حالة القصة |
| `/echo day <n>` (OP) | تقديم القصة لليوم n (للاختبار) |
| `/echo reset` (OP) | إعادة القصة من الصفر |

## النهايات
- **الأدلة الثلاثة**: قطعة الزجاج الزرقاء + رسالة المطوّر (غرفة السجلات أو الملجأ 2) + سجل الذاكرة (غرفة مخفية خلف الجدار المرقّع بالكوبلستون في غرفة السجلات).
- **ناقص أدلة / اخترت الوقوف / فشل البروتوكول** ← إيكو يختفي، تبقى قطعة الزجاج، وعند العودة لمكان الجهاز تسمع: «أنت رجعت... صح؟»
- **كل الأدلة + نجح البروتوكول** ← `ECHO-07 - MEMORY RESTORED: PARTIAL`.
- نسبة النجاح تتأثر بقراراتك (مواساة إيكو، الوعد، الرفض...) وبـ `protocolBaseChance` في الإعدادات. البروتوكول يستهلك كل أغراضك ومستويات خبرتك (`protocolSacrifice`).

## الأصوات والموسيقى والخامات
المولّدة هنا **placeholders** اصطناعية (`python tools/generate_assets.py`). استبدلها بتمثيل صوتي حقيقي وموسيقى حقيقية بنفس أسماء الملفات (OGG mono) داخل
`src/main/resources/assets/thelastplayer/sounds/`. موديل إيكو ثلاثي الأبعاد مبني بالكود (`EchoModel.java`)، وتقدر تستبدله بموديل من Blockbench لاحقًا. الخامات في `textures/entity/echo_0..4.png` (حسب المزاج) مع طبقة توهج `_glow`.

## ملاحظات
- النصوص عربية: غيّر لغة ماينكرافت إلى العربية لعرض صحيح للحروف.
- مصمم للاعب واحد (مالك القصة = أول من يشغّل الجهاز). اللعب الجماعي مؤجّل.
- الموسيقى المخصصة تُرسل للعميل عبر حزمة، لذلك لازم المود على الطرفين.
- كتل القصة غير قابلة للكسر في السرفايفل حتى لا تنكسر القصة.
- التقدم المؤقت داخل مشهد (Scheduler) لا يُحفظ؛ لو أغلقت اللعبة وسط مشهد، قد يضيع جزء منه. القصة نفسها (اليوم/الاختيارات/الذكريات) محفوظة في العالم.
